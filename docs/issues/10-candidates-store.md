# 10 — Candidates store (`candidates.yaml`) and schema

## Title

`src/store/candidates.ts`: machine-owned candidates schema, wholesale rewrite, lookups

## Summary

Implement the machine-owned candidate tier per DESIGN.md §7.3: schema, ordered
wholesale rewrite with generation metadata, and the read/lookup/update surface
used by extract (24), read commands (25), curation (26), and draft (37).

## Context

`candidates.yaml` is the only file `extract` writes; its determinism is the
core testability property of the pipeline. Draft (37) performs the one partial
update allowed: filling `suggestedDefinition`.

## Scope

- Schema + store + unit tests.

## Detailed Requirements

1. Zod schema `CandidatesFile` per §7.3, `.strict()`:
   `schemaVersion: 1`; `generatedBy` matching
   `^glossary@\d+\.\d+\.\d+(?:[-+][0-9A-Za-z.-]+)?$`; `generatedAt` ISO
   datetime (issue 03 format); `candidates: Candidate[]`.
   `Candidate`: `key` (non-empty), `surface`, `surfaces: string[]` (≥1,
   contains `surface`), `kind` enum as in 09, `score` finite number ≥ 0 with
   `Number.isInteger(score * 100)` (2-decimal rule), `extractors: string[]`
   (≥1, from the fixed id set `ja-domain|identifiers|abbreviations|
   doc-definitions`), `occurrences` positive int, `sources:
   {path, line, snippet?}[]` (1–5; `path` non-empty relative POSIX path with
   no leading `/` and no `..` segment; `line` positive int; snippet ≤ 200
   chars), `suggestedDefinition: string|null`, `suggestedDefinitionSource:
   'doc'|'llm'|null` (null iff definition null). Serialized key order = the
   §7.3 listing order, both file-level and per-candidate.
   ALL reads/writes go through yaml-io (issue 04) — no direct `yaml` import;
   `E_YAML_*` errors propagate unchanged.
2. `readCandidates(glossaryDir): {file: {schemaVersion, generatedBy, generatedAt} | null, candidates: Candidate[]}`
   - Missing file ⇒ `{file: null, candidates: []}` (extract not yet run — NOT
     an error; commands produce hints).
   - zod failure ⇒ RuntimeError `E_SCHEMA_INVALID` with file + first issues
     (machine file must not be hand-edited; hint says re-run extract).
     yaml-io failures (`E_YAML_INVALID`/`E_YAML_TOO_LARGE`) propagate as-is,
     never relabeled as schema errors.
3. `writeCandidates(glossaryDir, candidates, meta: {version, clock})`:
   - Sort by (score desc, key asc via compareCodepoint); enforce snippet
     control-char stripping and length caps HERE (last line of defense);
     write with header `GENERATED by 'glossary extract' — do not edit by hand`
     (yaml-io adds the `# ` prefix).
4. `updateSuggestedDefinitions(glossaryDir, updates: Map<key, {text, source: 'llm'}>): {updated: string[], notFound: string[], invalid: string[]}`
   — read; sanitize each text per DESIGN §12.4 (trim, strip control chars,
   collapse whitespace runs, cap 1000 chars); empty-after-sanitize ⇒ key
   reported in `invalid` and not written. Apply to matching keys only;
   rewrite ONCE preserving candidate order, all untouched fields, and the
   entire file metadata (`generatedBy`, `generatedAt`, header). No schema
   change (no extra fields).
5. `removeCandidates(glossaryDir, keys: Set<string>): {removed: string[], notFound: string[]}`
   — used by approve/reject (issue 26): read, drop matching keys, rewrite
   ONCE preserving remaining order and file metadata (same preservation rule
   as 4).
6. `candidateKeySet(candidates): Set<string>` helper.

## Acceptance Criteria

- [ ] Schema tests incl. surfaces-contains-surface rule, extractor id enum, source count 1–5, path/line constraints (absolute and `..` paths rejected), generatedBy pattern, score 2-decimal rule, suggestedDefinition/source null-pairing.
- [ ] write→read round-trip deep-equal; byte-golden for a 3-candidate JA/EN sample; header comment present; ordering rule enforced (equal scores → key order).
- [ ] Snippet containing a control character (U+0007) and a 500-char snippet are stripped/truncated on write.
- [ ] updateSuggestedDefinitions: 2 of 4 keys updated, 1 notFound, 1 empty-after-sanitize ⇒ `invalid`; file stays schema-valid and ordered; generatedBy/generatedAt byte-unchanged; a 1500-char text is capped at 1000.
- [ ] removeCandidates: removes 2, reports 1 notFound; remaining order and file metadata unchanged.
- [ ] Missing-file read returns `{file: null, candidates: []}` without throwing; alias-bomb / >1 MiB / 21-deep-nesting YAML each surface the issue-04 `E_YAML_*` error (not `E_SCHEMA_INVALID`).
