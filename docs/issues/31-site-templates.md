# 31 — Auto-escaping template engine and site pages

## Title

`src/site/templates/`: escaped `html` tagged template + index/term/tag/about pages with i18n and CSP

## Summary

Implement the HTML half of the site per DESIGN.md §11.1–11.2: a tiny
auto-escaping template system and the four page types, bilingual UI strings,
strict CSP meta, and no external references.

## Context

Term content is untrusted (abuse case AC1); the template layer is the XSS
defense. Keeping it hand-rolled (no engine dependency) makes escaping auditable
and the output deterministic.

## Scope

- Template module + page renderers + UI string tables + tests. Registered
  into 30's build orchestration.

## Detailed Requirements

1. Template engine `src/site/templates/html.ts`:
   - `html` tagged template returning `SafeHtml` (branded type). ALL
     interpolated values are escaped (`& < > " '` → entities) unless already
     `SafeHtml`. Arrays of SafeHtml join with ''. `null/undefined` → ''.
     Numbers stringified. Any other object type ⇒ TypeError (fail loud).
   - `unsafeRaw(s: string): SafeHtml` — exported but lint-fenced: allowed only
     inside `src/site/templates/` (eslint no-restricted-imports elsewhere);
     每 usage requires a `// SAFETY:` comment.
2. Layout: shared shell — `<!doctype html>`, `<html lang="<locale>">`, meta
   charset/viewport, **CSP meta exactly as DESIGN §11.2**, `<title>`,
   stylesheet link `assets/style.css` (relative), skip-link, header (site
   title linking index), main, footer (`generated by glossary` + about link).
   Script tag `<script type="module" src="assets/app.js"></script>` ONLY on
   index.html.
3. Pages (all links RELATIVE — site must work from any base path; baseUrl
   used only where absolute needed: nowhere in v1 — drop baseUrl usage,
   keep config reserved):
   - `index.html`: search box (`<input type="search">`, disabled + placeholder
     "loading…" until JS enables), kind/tag filter chips (static links to
     tag pages when no-JS), full term list `<ul>` grouped by kind (27's
     grouping), each item: term (link to term page), kind badge, first 120
     chars of definition (escaped, ellipsis).
   - `terms/<id>.html`: h1 term; meta table (reading, aliases, kind, tags
     linking tag pages); definition as `<p>` per paragraph (blank-line split);
     llm-provenance warning box when definitionSource==llm; examples list;
     sources list `path:line` as plain text (NO links to repo files — site is
     standalone; a config-free choice, documented); related terms links.
   - `tags/<tag>.html`: term list filtered; tag slug for filename =
     encodeURIComponent-safe transform: tags already match the schema pattern
     (letters/numbers/hyphen incl. JA) — filename = `tag-<termId-style hash8>`
     when tag contains non-ASCII else the tag itself (deterministic; both
     tested).
   - `about.html`: tool version, `generatedAt` (clock — the ONLY timestamp in
     the site), term/tag counts, link back.
4. i18n: `src/site/templates/strings.ts` — `{ja: {...}, en: {...}}` for all UI
   chrome (search placeholder, headings, badges, llm warning, footer). Locale
   from config.site.locale. Term CONTENT is never translated.
5. `escapeHtml` unit-fuzzable: property — output contains no raw `<`/`>`/`&`
   not part of an entity, for arbitrary inputs.
6. Deterministic: pages rendered in sorted order; no Math.random/Date outside
   about.html's injected clock.

## Acceptance Criteria

- [ ] Escaping property test + targeted vectors: `<script>`, `"><img onerror`, `javascript:` in a term (renders as text; href never constructed from content — assert no `href="javascript:` in any output).
- [ ] Golden HTML for index/term/tag/about over the e2e curated set (both locales for index).
- [ ] Every page passes: contains CSP meta; zero occurrences of `http://`/`https://` in output files; zero inline `<script>`/`style=` attributes; app.js referenced only from index.
- [ ] unsafeRaw usages all carry SAFETY comments (grep test); lint fence works (importing it from src/cli fails lint — test via eslint run).
- [ ] llm-flagged term shows the warning box (both locales snapshot).

## Validation

Golden tests + open the built fixture site via `python3 -m http.server`
manually once; screenshot in PR.

## Dependencies

30 (orchestration seam), 27 (grouping/sort rules shared — import, don't
duplicate).

## Non-goals

Client search behavior (32), dark mode/theming, Markdown rendering inside
definitions (v1 renders plain text — DESIGN §11.2), pagination.
